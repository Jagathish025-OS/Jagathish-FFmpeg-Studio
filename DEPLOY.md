# Deployment

1. Connect this GitHub repository to Render as a **Static Site**.
2. Build command: `npm install && npm run build`.
3. Publish directory: `dist`.
4. The Vite base path is configured as `/ffmpeg/` for https://jagathish.online/ffmpeg/.
5. Configure the custom domain and DNS using the current values shown by Render.

No backend environment variables are required for local browser processing.
